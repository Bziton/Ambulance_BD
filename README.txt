ЛОКАЛЬНИЙ САЙТ «СЛУЖБА ШВИДКОЇ ДОПОМОГИ»
1. Двічі клацніть Kursova.code-workspace
   (або VS Code -> File -> Open Workspace from File -> Kursova.code-workspace)
2. Натисни F5 (або Run -> Start Debugging, конфігурація «Запустити сайт»).
   Проєкт збереться, сайт запуститься, браузер сам відкриє http://localhost:5080
   Зупинити — Shift+F5 або червоний квадрат угорі.
   Без розширення C#: Terminal -> Run Task -> run, потім відкрий http://localhost:5080 вручну.
3. Або просто dotnet run пропишіть
