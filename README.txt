ЛОКАЛЬНИЙ САЙТ «СЛУЖБА ШВИДКОЇ ДОПОМОГИ»

Запуск із VS Code
1. Двічі клацни D:\Курсова\Kursova.code-workspace
   (або VS Code -> File -> Open Workspace from File -> Kursova.code-workspace)
2. Якщо VS Code запропонує встановити розширення C# — погодься (потрібне для F5).
3. Натисни F5 (або Run -> Start Debugging, конфігурація «Запустити сайт»).
   Проєкт збереться, сайт запуститься, браузер сам відкриє http://localhost:5080
   Зупинити — Shift+F5 або червоний квадрат угорі.
   Без розширення C#: Terminal -> Run Task -> run, потім відкрий http://localhost:5080 вручну.

Запуск без VS Code
- Двічі клацни start_site.bat (або в терміналі: cd AmbulanceSite, потім dotnet run).

Перед запуском закрий попереднє вікно сайту, якщо воно ще відкрите,
інакше збірка не зможе перезаписати файли.

Пароль MySQL лежить у AmbulanceSite\appsettings.json (рядок Pwd=...).

База даних ambulance_service створюється автоматично при першому запуску
(скрипти sql\01_schema.sql і sql\02_data.sql). Кнопка «Перестворити базу даних»
на вкладці «Цілісність» повертає початкові тестові дані.

Папка sql
- 01_schema.sql — DDL-скрипт (створення бази і таблиць)
- 02_data.sql   — тестові дані
- 03_users.sql  — облікові записи dispatcher і analyst з розмежуванням прав
  (виконується вручну в MySQL Workbench, сайт його не запускає)
